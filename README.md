# Better Than IME
_This mod uses a modified version of Fabric (Babric) and is designed only for Better than Adventure, a heavily modified version of Minecraft b1.7.3! For more information, join the discord server provided on this projects page._

This mod fixes in-game IME conflicts for the "Better Than Adventure!" fork-mod, using Babric loader, assisted with Gemini.

## Features
* **UI Support**: Native support for Chat Screens, Sign Editing, Creative Searching Panel, etc.
* **IME State Memory**: Automatically remembers and restores your previous input mode (e.g., Chinese or English).
* **Command Awareness**: Detection for commands. It can automatically disable the IME in command mode unless you are typing specific commands like `/kill` or `/tell` .
* **Pinyin Preview**: show pinyin input when typing, so you do not need guess what you are typing anymore. Input method will also move to where you are typing.

## Tips
* Better performance if you enable Borderless Fullscreen in full screen, or the screen will blacken for a while when typing.
